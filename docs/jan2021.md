# January 2021 PP investigation

The three well-known January 2021 score values have a reproducible historical
source oracle. The matching source is the upstream osu! repository at commit
[`1ba586a683b3321cf7806d9dabf068983d0bd27b`](https://github.com/ppy/osu/commit/1ba586a683b3321cf7806d9dabf068983d0bd27b),
committed on 13 January 2021. The release announcement for this calculator
rework followed on 14 January 2021.

## Target values

|   Score ID | Target display | Historical source result | Rounded result |
| ---------: | -------------: | -----------------------: | -------------: |
|  948327084 |         1150pp |     1149.8228113262194pp |         1150pp |
| 1191045921 |         1258pp |     1258.4233744896321pp |         1258pp |
| 1314141259 |         1255pp |     1254.7815326027812pp |         1255pp |

These results were generated by the source calculator from the checked-in raw
`.osu` maps and the score accuracy, combo, and main hit counts. The `CL`
entries in these fixtures are legacy-score markers; the January 2021 source
predates the Classic mod and they are ignored by the historical probe. `NC`
is handled by the source as Nightcore.

## Important distinction

The later fork snapshot currently listed as the `huismetbenen` Jan 2021 source,
[`e3f882846f0f4dfd7e00ad7a8199a6d9c5f9c7c5`](https://github.com/Givikap120/osu/commit/e3f882846f0f4dfd7e00ad7a8199a6d9c5f9c7c5),
does not reproduce these archived displays. It produces `1150.263957pp`,
`1261.555130pp`, and `1260.642972pp` respectively. That snapshot contains
later fixes and is therefore not the oracle for these three historical values.

The older source is not yet a general Jan 2021 parity proof: several other Jan
fixtures in this repository still differ from their archived decimal values.
The result currently supports the three requested rounded score displays, not
an implemented `jan2021` calculator.
