## HUISMETBENEN DOCUMENTED CHANGES

oct2025 2025-10-29: awaiting.

mar2025 2025-03-06: This page uses the pp version that was active from March 2025 until the new changes in November 2025. Changes that were introduced in this version include:

- Acute angle bonus rework (aim slop nerf)
- Wiggle bonus
- Slider end drop penalty fix
- Speed punishment for improper tapping based on estimated UR (rake nerf)
- Flashlight spinner fix
- Autopilot support

oct2024 2024-10-28: This page uses the pp version that was active from October 2024 until the new changes in March 2025. Changes that were introduced in this version include:

- Combo Scaling Removal - Miss penalty change (now scaled by amount of difficult sections)
- Support for lazer slideracc
- Rhythm abuse fix
- Speedflow nerf (additive instead of multiplicative)

sep2022 2022-09-30: This page uses the pp version that was active from September 2022 until the new changes in October 2024. Changes introduced in this version include:

- Worst case speed scaling
- Remove non-overlapping velocity change bonus (Zan'ei nerf)
- Doubletap doubles nerf
- Touchscreen now affects Star Rating
- FL difficulty calculation was improved (HD support and repetitive angle nerf)
- Effective miss count was improved (smooth and clamped by amount of mistakes)
- Aim slightly buffed
- Low AR was nerfed
- Speed 50s nerfed reduced

The rankings are not entirely accurate due to not all scores being recalculated, but scores should have the correct pp values. This was the last version of pp before the "combo scaling removal" rework (https://osu.ppy.sh/home/news/2024-10-28-performance-points-star-rating-updates). Since this change caused a lot of changing values, some of your older top ranks might not show up on this page.

nov2021 2021-11-09: This page uses the pp version that was active from November 2021 until the new changes in September 2022. Changes introduced in this version include:

- Slideraim change
- Added High BPM bonus
- Added Velocity change bonus
- Wide angle buff is now stronger when angles are not repeated
- Rhythm calc added as multiplier to speed
- Added FL difficulty calculation
- Star Rating formula change
- Remove 300BPM speed cap (now it's 600BPM)
- Sliderbreak estimation (effective miss count)
- Spinner bug fix
- Added support for Blinds and Relax

jul2021 2021-07-27: This page uses the pp version that was active from July 2021 until the new changes in November 2021. Changes introduced in this version include:

- Diffspike nerf
- AR length bonus rebalance (mid length buff)
- AR and FL bonuses are mutually exclusive now (FGSky nerf)

jan2021 2021-01-16: This page uses the pp version that was active from January 2021 until the new changes in July 2021. Changes that were introduced in this version include:

- Add length bonus for AR bonus
- NF now scales with misses, where FC has no NF penalty
- SO now scales with amount of spinners instead of flat penalty
- New miss penalty curve: more lenient on low misscount, harsher on high misscount
- New speed acc scaling: harsher on low acc
- Speed 50s nerf (anti-doubletap)

feb2019 2019-02-07: This page uses the pp version that was active from February 2019 until the new changes in January 2021. Changes that were introduced in this version include:

- Added wide angle aim bonus
- Added speed bonus for 200-330 BPM
- Nerfed spaced streams
- Buffed long sliders
- Updated speed acc scaling: harsher on low acc
- FL nerf on short maps, buff on long maps
- HD buff. Aim and acc HD buff (2% -> current 8%). Speed HD rebalance: high AR nerfed, low AR buffed
- High AR aim reward nerfed from 0.45 to current 0.3
- Added high AR speed bonus (matching aim)

may2018 2018-05-14: This page uses the pp version that was active from May 2018 until the new changes in February 2019. Changes that were introduced in this version include:

- Changed aim HD buff from 18% to AR-dependant (The lower the AR, the more bonus you have). Bonus is much smaller on normal AR compared to before (18% -> 4% on AR 10)
- Added speed HD buff (also 18%)

dec2017 2017-12-15: This page uses the pp version that was active from December 2017 until the new changes in May 2018. Changes that were introduced in this version include:

- Added TD nerf for aim pp

jul2015 2015-07-01: This page uses the pp version that was active from July 2015 until the new changes in December 2017 (originally shown on this site as "ppv2 (2016)"). The exact changes are not known, although this version was labeled as "CS hotfix"

feb2015 2015-02-12: This page uses the pp version that was active from February 2015 until the new changes in July 2015. Changes introduced in this version include:

- Make AR bonus start from 10.33 instead of 10, and change the curve according to new starting point
- Make FL bonus scale with length

jan2014 2014-01-26: This page uses the pp version that was active from February 2015 until the new changes in July 2015. It was reverse engineered by Givikap120 to resemble the historic values as closely as possible, but some values might be wrong
